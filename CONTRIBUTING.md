# 🚀 How to Contribute

### 1. Fork the Repository

Click the **Fork** button on GitHub.

### 2. Clone Your Fork

```bash
git clone https://github.com/your-username/Resume-Evaluator-NLP.git
```

### 3. Navigate to the Project

```bash
cd Resume-Evaluator-NLP
```

### 4. Create a New Branch

```bash
git checkout -b feature/your-feature-name
```

### 5. Install Dependencies

```bash
pip install -r requirements.txt
```

### 6. Make Your Changes

Implement your feature or bug fix while following the project's coding standards.

### 7. Test Your Changes

Run the application and verify that everything works correctly.

```bash
streamlit run app.py
```

### 8. Commit Your Changes

```bash
git add .

git commit -m "Add: Short description of your changes"
```

### 9. Push Your Branch

```bash
git push origin feature/your-feature-name
```

### 10. Open a Pull Request

Submit a Pull Request with:
- A clear title
- Description of your changes
- Screenshots (if UI changes)
- Related issue number (if applicable)

# 📋 Contribution Guidelines

Please follow these guidelines before submitting a Pull Request:

- Follow Python best practices (PEP 8).
- Write clean, readable, and maintainable code.
- Keep Pull Requests focused on a single feature or fix.
- Test your code before submitting.
- Update documentation if required.
- Avoid breaking existing functionality.
- Add comments where necessary.
- Ensure your code is free from unnecessary files.

---

# 🐞 Reporting Issues

If you discover a bug or have a feature request:

1. Search existing issues first.
2. Create a new GitHub Issue if none exists.
3. Provide a clear description.
4. Include reproduction steps.
5. Attach screenshots or error logs if applicable.
